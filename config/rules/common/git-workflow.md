# Git Workflow

## Commit Message Structure

Format: `<type>: <description>`
Types: feat, fix, refactor, docs, test, chore, perf, ci

Optional body for WHY (not WHAT).

## Pull Request Process

- Review complete commit history, not just the latest change
- Run `git diff [base-branch]...HEAD` to see full scope
- Write a thorough PR summary
- Include test plan with TODO checklist
- Push new branches with `-u` flag
